# Proyecto: Tutor Virtual Inteligente 🎓

Este proyecto es un **Tutor Virtual Inteligente** interactivo desarrollado con Python y Streamlit. Permite a los alumnos interactuar con un asistente conversacional que mantiene el contexto de la sesión, explica conceptos de manera didáctica y realiza preguntas de comprobación.


---

### Proyecto Escolar LLM

Inicialmente fue un proyecto con intenciones de utilizar la API de OpenAI, pero debido al costo que generaba se optó por por utilizar la API de Gemini

Objetivos de aprendizaje

1. Entender el papel de los Modelos de Lenguaje de Gran Escala (LLM) en la inteligencia artificial moderna.

2. Familiarizarse con el uso del API de OpenAI para interactuar con modelos de lenguaje de gran escala.

3. Desarrollar habilidades prácticas en proyectos utilizando modelos de lenguaje de gran escala.

4. Aplicar técnicas de procesamiento de lenguaje natural (NLP) en escenarios del mundo real.
